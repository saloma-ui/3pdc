# Explicam la nostra maqueta

Utilitzam el model per comunicar coneixement científic

<p class="pv-meta">Explicació individual a partir d’un producte de grup</p>

</section>

<section class="pv-seccio" markdown="1">

## No basta dir-ne el nom

En una explicació científica hem de:

- identificar correctament l’estructura;
- explicar-ne la funció;
- utilitzar vocabulari científic;
- relacionar l’explicació amb el model.

<aside class="pv-avís">
La maqueta és del grup, però cada membre demostrarà individualment què ha après.
</aside>

</section>

<section class="pv-seccio" markdown="1">

<span class="pv-num-pregunta">1</span>

## Primera estructura

<p class="pv-pregunta">Quina estructura explicaràs?</p>

<div class="pv-quadern">
  <strong>AL QUADERN</strong>
  <span>Escriu-ne el nom i prepara com l’assenyalaràs damunt la maqueta.</span>
</div>

</section>

<section class="pv-seccio" markdown="1">

<span class="pv-num-pregunta">2</span>

## Prepara l’explicació

<div class="pv-cadena">
  nom de l’estructura → què és o on es troba → funció principal
</div>

<div class="pv-quadern">
  <strong>AL QUADERN</strong>
  <span>Redacta dues o tres frases seguint aquest ordre. Després practica-les sense llegir-les literalment.</span>
</div>

</section>

<section class="pv-seccio" markdown="1">

<span class="pv-num-pregunta">3</span>

## Segona estructura

<p class="pv-pregunta">Quina segona estructura explicaràs, si el professor t’ho indica?</p>

<div class="pv-quadern">
  <strong>AL QUADERN</strong>
  <span>Escriu-ne el nom i prepara’n l’explicació amb el mateix esquema.</span>
</div>

</section>

<section class="pv-seccio" markdown="1">

<span class="pv-num-pregunta">4</span>

## Per què és un model?

<p class="pv-pregunta">Completa amb les teves paraules: «La nostra maqueta és un model perquè…»</p>

<div class="pv-quadern">
  <strong>AL QUADERN</strong>
  <span>Explica què representa i en què es diferencia d’una cèl·lula real.</span>
</div>

</section>

<section class="pv-seccio pv-tancament" markdown="1">

## Durant l’exposició

<ul class="pv-llista-control">
  <li>Assenyala l’estructura correcta.</li>
  <li>Explica’n la funció.</li>
  <li>Utilitza els termes científics.</li>
  <li>Parla de manera comprensible.</li>
  <li>Mira la maqueta i les persones que t’escolten.</li>
  <li>Demostra que entens el model complet.</li>
</ul>

<p class="pv-recordatori">Pots consultar el guió abans de començar, però l’objectiu és explicar, no llegir.</p>

</section>
